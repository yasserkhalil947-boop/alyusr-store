# AL YOSSER 3M ERP

نظام مستقل للمحاسبة والمبيعات والمشتريات والمخازن لمكتبة اليسر 3M. هذا المستودع منفصل عن المتجر الإلكتروني وعن مشروع Firebase الخاص به.

## الوضع الحالي
- حزمة تأسيس أولية لخدمة ASP.NET Core API.
- مسودتا PostgreSQL: `001_foundation.sql` ثم `002_integrity_and_posting.sql`.
- شعار وهوية المكتبة داخل `Assets/Branding/`.
- واجهات البيع والشراء والمرتجعات واللمس، وتسجيل الدخول والصلاحيات، والترحيل الكامل، والتقارير والنسخ الاحتياطي ما زالت أعمالاً مطلوبة وليست مكتملة.

## متطلبات التشغيل الأولي
راجع `docs/README_AR.md` و`docs/NEXT_STEPS_AR.md` قبل التشغيل. يتطلب المشروع .NET 10 SDK وPostgreSQL. لا تضع كلمة مرور حقيقية أو أسراراً في GitHub. غيّر كلمة المرور محلياً فقط، ولا ترفع ملف إعدادات يحتوي بيانات اعتماد حقيقية.

## تنبيه
هذه قاعدة تأسيس ومسودات SQL وليست إصداراً جاهزاً للاستخدام المحاسبي الفعلي. لم يتم إثبات تشغيل migrations على PostgreSQL في بيئة المستخدم أو إجراء اختبارات تكامل كاملة. لا تستخدمها على بيانات فعلية قبل المراجعة والاختبار والنسخ الاحتياطي.
